Windows 11 → Proxmox

A physical-to-virtual migration workflow designed to preserve a recoverable path while moving an existing Windows installation into Proxmox VE.

What this guide covers

The complete guide will walk through preparation on the source Windows computer, creation and verification of a VHDX image, Proxmox installation, VM import and configuration, validation, cleanup, and backup.

Safety-first migration

The intended workflow favors a second SSD or NVMe for Proxmox when practical, allowing the original Windows disk to remain intact as a physical fallback while the virtualized installation is validated.
